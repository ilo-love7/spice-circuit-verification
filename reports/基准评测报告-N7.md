## §1 命题与环境

### 1.1 提案要求

用 PySpice（Python 驱动 ngspice 引擎）搭建 RC / 有源滤波器与运放电路，脚本化完成 AC 扫频与瞬态仿真，与理论传递函数对比误差，并做 ±5% 元件容差蒙特卡洛分析，输出幅频特性良率曲线。

### 1.2 环境决策（如实标注偏离）

| 项 | 提案 | 实际 | 说明 |
|---|---|---|---|
| 网表前端 | PySpice | **PySpice 1.5**（pip 安装） | Circuit API 建网表 ✅ |
| 仿真引擎 | ngspice（PySpice 驱动） | **ngspice-46 win64 `ngspice_con.exe` 批处理** | 见下 |
| 理论对比 | scipy.signal | **scipy 1.18** | 传递函数由元件值解析推导 |
| Python | Colab CPU | **本地 Python 3.12.10**（`D:\项目\venvs\flsoh-py312`） | 更快、可复现 |

**偏离说明**：PySpice 官方推荐共享库模式（`libngspice-0.dll` + `NgSpiceShared`）。实测社区 ngspice Windows 构建（Schemline-IC/ngspice-builds v46）只带 `ngspice_con.exe`，不含共享库 DLL；SourceForge 官方安装包脚本下载被 Cloudflare 拦截。因此采用 **PySpice 做网表前端 + ngspice 批处理引擎 + 自研 ASCII raw 解析** 的三层结构：

1. PySpice `Circuit` API 生成 SPICE 网表（提案的"PySpice 建立网表"）；
2. `ngspice_con.exe -b -r out.raw` 批处理仿真（ngspice 引擎本体）；
3. `src/engine/rawparse.py` 解析 ASCII raw 文件（`set filetype=ascii`）。

字符串模板网表（`src/circuits/builders.py`）与 PySpice 网表（`src/circuits/pyspice_build.py`）双轨并行：前者蒙特卡洛高效，后者验证 EDA 流水线。**两者输出在 20 点/十倍频网格上逐点一致**（单测 `test_pyspice_netlist_matches_string`）。另：PySpice 1.5 的 `VoltageSource` 未实现 `ac` 参数，网表后处理补 `AC 1` 激励（`_inject_ac`）。

**已修环境项**：spinit 的 code model 相对路径在含中文字符的安装根目录下加载失败（XSPICE 模型本项目用不到，已移除 codemodel 行）；`set filetype=ascii` 在 `share/ngspice/scripts/spinit` 启用。

### 1.3 电路与拓扑（理论式全部由节点法手推，仿真零拟合）

| 电路 | 拓扑 | 理论传递函数 |
|---|---|---|
| 一阶 RC 低通 | Vin-R-C-GND | `H = 1/(1+sRC)` |
| Sallen-Key 低通（单位增益） | Vin-R1-A-R2-B(=V+=Vout)，C1: A→Vout，C2: B→GND | `H = 1/(1+s(R1+R2)C2+s²R1R2C1C2)` |
| Sallen-Key 带通（等元件） | Vin-C1-A-R2-B，R1: A→GND，C2: B→GND，Vout=K·Vb | `H = K·s/(RC) / (s²+3s/(RC)+1/(R²C²))` |
| 反相放大器 | Vin-R1-inv-Rf-out，运放 VCVS 增益 1e6 | `H = −Rf/R1`（有限 A 修正如右） |

运放统一用 VCVS 理想模型（开环增益 `A_OL = 1e6`）。Sallen-Key 低通元件取 **Butterworth**：R1=R2=10 kΩ，C2=11.25 nF，C1=2·C2=22.5 nF → f0=1000.35 Hz，Q=1/√2。带通等元件结构 Q=1/3 是**拓扑约束**（v1.1 深化方向）。

## §2 AC 扫频 vs 理论

测试网格：20 点/十倍频。误差 = 20log10|H_sim| − 20log10|H_theory|。

| 电路 | 最大幅值误差 (dB) | 均方误差 (dB) | 最大相位误差 (deg) | 主要误差来源 |
|---|---|---|---|---|
| 一阶 RC 低通 | **7.1e-15** | 2.2e-15 | 1.4e-14 | 机器精度 |
| Sallen-Key 低通 | **1.74e-05** | 1.04e-05 | 2.86e-05 | 有限开环增益 A=1e6 |
| 反相放大器 vs 理想 | 9.55e-05 | — | 0 | 有限 A：−10 → −9.999890 |
| 反相放大器 vs 有限-A 理论 | **0** | — | 0 | 与修正理论完全一致 |
| Sallen-Key 带通 | **1.4e-14** | 4.1e-15 | 2.1e-14 | 机器精度（理想增益级） |

**要点**：
- 无运放（RC、BP 理想增益级）的电路与解析传递函数在**机器精度**上一致——验证了解析推导与 ngspice 求解器双向正确。
- 含运放电路的残余误差（1e-5 dB 量级）**不是 bug**，是 A=1e6 有限增益的物理效应：反相增益理论值 −Rf/R1/(1+(1+Rf/R1)/A) = −9.999890，仿真精确命中（误差 0.0000%）。
- 反相放大器输出幅度 9.999890（|H|）与有限-A 理论一致到 6 位有效数字。

| RC 正弦@fc 相位 | −45.0° | −43.2°（过零插值分辨率限制） | 1.8° |

| SK LP 正弦@f0 幅度 | 0.707107 | 0.706564 | 0.077% |

## §4 ±5% 元件容差蒙特卡洛

协议：均匀分布 ±5% 独立扰动全部 R/C，n=400/电路，种子 20261110，20 点/十倍频 AC 扫频。良率判据：|H(f_spec)| 偏离名义理论 < 5%（RC）/ < 15%（SK，f_spec=f0 处名义值 0.707）。

| 电路 | fc 理论 (Hz) | fc 均值 ± std (Hz) | std/标称 | 良率 |
|---|---|---|---|---|
| RC 低通 | 159.15 | 159.53 ± 6.32 | 3.97% | 100%（±5% 窗） |
| SK 低通 | 1000.35 | 994.39 ± 35.96 | 3.62% | 100%（±15% 窗） |

- RC 的 fc 分布宽度（3.97%）与一阶误差传播一致：fc ∝ 1/(RC)，±5% R、±5% C 独立均匀 → fc 相对 std ≈ (0.05/√3)·√2 ≈ 4.1% ✓（**误差传播公式被蒙特卡洛复现**）。
- |H(fc)| 分布：0.70782 ± 0.01419（理论 0.70711），相对 std 2.0%。
- **幅频特性良率曲线**（`figures/mc_yield_curve.png`）：低频段良率接近 100%，fc 附近跌落到 ~50%，远高于 fc 后回升（偏差被 −20dB/dec 斜率压缩）——容差最敏感区在转折频率附近，这正是工程上"截止频率标定"必须给出容差预算的定量依据。
- 蒙特卡洛幅频曲线族（`figures/mc_response_family.png`）展示 60 条抽样响应围绕名义曲线的散布。

## §5 结论

1. **流水线可用**：PySpice 建网表 → ngspice 批处理 → raw 解析 → scipy 理论对比，全脚本化、单测覆盖（20 项）。
2. **精度上限**：无源/理想电路对解析解到机器精度（1e-14 dB）；运放电路残余误差由有限开环增益决定（1e-5 dB @ A=1e6），且与有限-A 理论完全一致。
3. **瞬态链路**：正弦幅度/相位、阶跃时间常数全部 ≤0.1% 误差（采样分辨率内）。
4. **容差定量**：±5% 元件容差 → fc 散布 ±3.6–4.0%（与误差传播公式一致）；良率曲线给出频率相关的合格概率，转折频率附近最敏感。
5. **可复现**：`run_all.sh` 一键（pytest + 00–06 脚本）；400×2 蒙特卡洛约 5.5 分钟。

# 第二轮：v1.1 深化（A 非理想运放 / B 高阶滤波 / C 容差方法学）

## §7 深化 A：非理想运放（有限 GBW / 压摆率）

### 7.1 宏模型

单极点限流跨导宏模型（B 源实现，v1.0 的理想 VCVS 由此升级）：

```
B1 0 nc I = max(-Imax, min(Imax, gm*(V(V+)-V(V-))))
Rlag nc 0 …   Cc nc 0 …   E1 out 0 nc 0 1
```

小信号 A(s) = A0/(1+s/wb)，A0 = gm·Rlag，GBW = gm/(2πCc)；
大信号电流限幅 Imax → SR = Imax/Cc。设计目标：GBW = 10 MHz、A0 = 1e5、SR = 10 V/µs
（gm = 1 mS，Rlag = 100 MΩ，Cc = 15.92 pF，Imax = 159.2 µA）。

### 7.2 AC：闭环精确理论 vs 仿真

反相放大闭环（G = −10，噪声增益 NG = 11）：

H(jω) = −G·A(s)/(A(s) + NG)

ngspice vs 精确理论：**最大误差 7.11e-15 dB / 2.84e-14°（机器精度）**；
同相缓冲 A/(1+A) 同样 7.11e-15 dB。B 源 max/min 在 AC 小信号线性化正确，限流非线性不污染 AC。

### 7.3 经典 GBW/NG 规则的精确偏差

闭环极点精确解 ωp = wb·(A0+NG)/NG，即 f_p = (GBW/NG)·(1 + NG/A0)。
经典规则 fc ≈ GBW/NG 的相对偏差恰为 **−NG/A0**：

| G | NG | fc 实测 | 经典 GBW/NG | 精确极点 | 经典偏差 |
|---|---|---|---|---|---|
| 1 | 2 | 4.988e6 | 5.000e6 | 5.000e6 | −0.002% |
| 10 | 11 | 9.070e5 | 9.091e5 | 9.092e5 | −0.011% |
| 50 | 51 | 1.957e5 | 1.961e5 | 1.962e5 | −0.051% |
| 100 | 101 | 9.888e4 | 9.901e4 | 9.911e4 | −0.101% |

（fc 实测与精确极点的额外 −0.237% 由 −3.00 dB vs −3.0103 dB 判据差异解释，见 7.4。）

### 7.4 方法学发现：fc 提取的判据与插值陷阱

排查 fc 实测偏小 0.24% 的过程（全程如实记录）：

1. **判据差异**：极点是 −3.0103 dB（半功率）点；工程常用的 −3.00 dB 点须乘 √(10^0.3−1) = 0.99763。
   909191 × 0.99763 = 907033 Hz —— 与实测 907034 Hz 吻合到 0.0002%。**0.24% 偏差全部由判据定义解释。**
2. **插值偏差**：v1.0 的 log-f 线性插值在 15 点/decade 网格上有 −0.5% 系统偏差；
   v1.1 改用 log-f 三次样条 + brentq（`cutoff_precise`），15→60 点/decade 收敛到 0.0002%。
3. **结论**：跨来源比较 fc 时必须统一判据（−3.00 或 −3.0103）与提取算法。

### 7.5 压摆率

方波大信号（±0.5 V，10 kHz）：实测最大斜率 **10.0028 V/µs vs 规格 10.0000 V/µs（+0.028%）**。
小信号方波（±5 mV）实测斜率 0.333 V/µs = SR 的 3.3%（SR 未触发，斜率由闭环带宽限制，
与 ΔV·2πfc 估计 0.57 V/µs 同量级；离散时间步长使实测略低）。

## §8 深化 B：4 阶 Butterworth 级联（两级 Sallen-Key）

### 8.1 设计与传递函数

Q1 = 1/(2sin(π/8)) = 0.5411961，Q2 = 1/(2cos(π/8)) = 1.3065630，f0 = fc = 1 kHz，
等 R 设计（Q = ½√(C1/C2)，R = 1/(2Q·ω0·C2)）。级联理论 H = H1·H2 vs `scipy.signal.butter(4)`：
**最大误差 5.68e-14 dB**。ngspice 缓冲级联 vs 理论 5.21e-5 dB（有限 A=1e6 的运放效应，与 v1.0 SK 结论一致）。

### 8.2 加载效应：负结果与对照

| 级联方式 | 0–10fc 幅值偏差 |
|---|---|
| 两级 SK（直接级联 vs 级间缓冲） | **0.0000 dB** |
| 两级无源 RC（直接 vs 缓冲） | **3.5218 dB** |

SK 级联**天然隔离**：每级输出由理想电压源（运放输出）驱动，次级输入阻抗不回传到前级
——「加缓冲」是冗余操作。作为对照，无源 RC 直接级联加载显著（3.5 dB）。
这是一个被数据否证的设计假设（「级间需要缓冲」），如实保留负结果。

### 8.3 群延迟与阶跃

群延迟 τg = −dφ/dω：ngspice vs 理论最大差 **1.41e-9 s**（100 Hz–10 kHz），τg(f0) = 0.5791 ms。
阶跃响应：

| 电路 | 过冲 | 上升时间 (10–90%) | 2% 稳定时间 |
|---|---|---|---|
| 4 阶 Butterworth | 10.83% | 387 µs | 1.574 ms |
| 单节 Q=0.707（2 阶 Butterworth） | 4.32% | 342 µs | — |

与教科书标准值（4 阶 Butterworth ≈ 10.8%，2 阶 ≈ 4.3%）一致。

## §9 深化 C：容差方法学（WCA / 灵敏度 / 良率优化）

### 9.1 最坏情况分析 vs 蒙特卡洛（SK f0=1 kHz，±5% 均匀）

| 指标 | 值 |
|---|---|
| WCA 16 角点最坏偏差 | 10.803%（= (0.95)⁻² − 1） |
| MC 最坏样本偏差（n=50000） | 10.282% |
| 解析 σ(fc)/fc = tol/√3 | 2.8868% |
| MC σ(fc)/fc | 2.8860% |
| **解析/MC 比** | **1.00026** |

WCA 角点是分布的理论端点，有限 MC 样本几乎不可达（50000 样本仍差 0.5 个百分点）。
解析误差传播与 MC 标准差吻合到 0.03%——MC 的统计噪声、测量噪声（v1.0 的 fc 提取误差）
在此被彻底分离。RC 一阶对照：解析 4.0825% vs MC 4.0704%。

### 9.2 灵敏度排序（S = d|H|/|H| ÷ dx/x，数值微分 ±0.1%）

| 元件 | @ f_spec = 700 Hz（过渡带） | @ f0 = 1 kHz |
|---|---|---|
| R1 | −0.303 | −0.500 |
| R2 | −0.303 | −0.500 |
| C1 | +0.129 | **0.000** |
| C2 | **−0.736** | **−1.000** |

**f0 处 C1 灵敏度精确为零**：|H(jω0)| = Q，而 ω0 ∝ C1^(−1/2)、Q ∝ C1^(+1/2)，
扰动 C1 时谐振点移动与峰值变化一阶对消（单测 `test_sensitivity_c1_zero_at_f0` 钉住该解析性质）。
f0 处 C2 灵敏度 −1.0、R −0.5 与 |H| = Q = ½√(C1/C2)（R1=R2 设计）解析一致。

### 9.3 良率优化（|H(f_spec)| 偏差 <5% 判析，解析抽样 n=20000）

| 容差方案 | 良率 |
|---|---|
| 全部 ±5% | 97.30% |
| 仅 C2 加严到 ±1% | **100.00%** |
| 仅 R2 加严到 ±1% | 99.27% |
| 仅 R1 加严到 ±1% | 99.18% |
| 仅 C1 加严到 ±1% | 97.51%（几乎无效） |
| 全部 ±1% | 100.00% |

**结论：良率优化应加严灵敏度最高的元件（C2），而非全面加严**——
单项加严 C2 即可 97.3%→100%，而加严最不敏感的 C1 只提升 0.2 个百分点。
良率-容差扫描（全 ±1%→±10%）：100/100/100/99.8/97.3/83.7/64.0%；
良率-判据扫描（固定 ±5%，判据 ±1%→±10%）：26.7/52.6/74.2/97.3/100/100%。

## §10 v1.1 结论

1. **非理想运放宏模型**（单极点限流 B 源）在 AC 与瞬态两侧同时闭环验证：
   AC 对精确理论机器精度，SR 实测 +0.028%。经典 GBW/NG 规则偏差精确等于 −NG/A0，
   −3 dB 判据换算因子 √(10^0.3−1)=0.99763 解释全部残差。
2. **4 阶 Butterworth 级联**与 scipy 标准设计 5.68e-14 dB 一致；阶跃过冲命中教科书值。
   SK 级联的加载效应为零（运放输出隔离）——「加级间缓冲」是伪需求，无源 RC 对照 3.5 dB 反衬。
3. **容差方法学**：解析误差传播与 MC 标准差吻合到 0.03%；WCA 角点是 MC 不可达的理论端点；
   灵敏度排序（含 f0 处 C1=0 的解析对消）直接给出良率优化方向：加严 C2 单项即可达 100% 良率。
4. **fc 提取的三个坑**（判据定义 / 插值偏差 / 网格密度）已系统化为 `cutoff_precise`，
   后续任何截止频率比较都应统一判据与算法。

# 第三轮：v1.2 深化（E16 MFB 带通 / E17 噪声 / E18 压摆瞬态）

本轮正面回应 §6 遗留的两项（MFB 带通、`.noise` 噪声），并把 v1.1 §7.5 只测了方波斜率的大信号瞬态补成完整的失真/带宽方法学。三组实验全部沿用 v1.0 的口径：**解析式由节点法手推、仿真零拟合、负结果如实保留**。

## §11 深化 D：MFB 带通 —— 突破 Sallen-Key 的 Q=1/3 结构约束

### 11.1 拓扑与手推传递函数

v1.0 的等元件 SK 带通 `H = K·s/(RC)/(s²+3s/(RC)+1/(R²C²))` 的 Q ≡ 1/3，是**拓扑硬约束**（§6 标注）。本轮改用多路反馈（MFB）带通：

```
R1: Vin → n1        R2: n1 → GND
C1: n1  → n2        C2: n1 → Vout
R3: n2  → Vout      运放 V+ = GND, V− = n2, Vout = A_OL·(0 − V(n2))
```

Vout 经 C2（回 n1）与 R3（回 n2）**两条**路径反馈，故称 multiple feedback。理想运放下 V(n2)=0、输入电流为 0：

```
KCL@n2 :  −s C1 V(n1) − Vout/R3 = 0                 → V(n1) = −Vout/(s C1 R3)
KCL@n1 :  (V(n1)−Vin)/R1 + V(n1)/R2 + s C1 V(n1) + s C2 (V(n1)−Vout) = 0

H(s) = −(s/(C2 R1)) / [ s² + s·(C1+C2)/(C1 C2 R3) + (1/R1+1/R2)/(C1 C2 R3) ]
```

由此得三个设计量（全部进入 `src/theory/mfb.py`）：

```
w0²  = (1/R1 + 1/R2)/(C1 C2 R3)
w0/Q = (C1 + C2)/(C1 C2 R3)
|H(jw0)| = Q/(C2 R1 w0)
```

设计式（给定 f0、Q、C1、C2、ρ=R1/R2）：`R3 = Q(C1+C2)/(C1C2 w0)`，
`1/R1 + 1/R2 = w0 Q (C1+C2)`，`R2 = (1+1/ρ)/(w0 Q (C1+C2))`，`R1 = ρR2`。
C1=C2 时闭环峰值增益 **`H0 = 2Q²/(1+ρ)`**。

### 11.2 Q 自由度与 AC 对照

f0 固定为 v1.0 SK 带通的 1591.549 Hz，C=10 nF，200 点/十倍频 AC 扫频。峰值用 log-f 三次样条精化（沿用 v1.1 §7.4 的插值教训，网格 argmax 会带来 ~0.1% 伪影与固定峰位偏移）。

| Q 目标 | H0 理论 | H0 仿真 | Q(3dB) 实测 | AC 最大误差 (dB) |
|---|---|---|---|---|
| 0.3333 | 0.1111 | 0.1111 | 0.333 | 1.06e-05 |
| 1 | 1.000 | 1.000 | 1.000 | 2.61e-05 |
| 2 | 4.000 | 4.000 | 1.999 | 7.82e-05 |
| 5 | 25.000 | 24.999 | 4.989 | 4.42e-04 |
| 10 | 100.000 | 99.972 | 9.916 | 1.73e-03 |

残差全部来自运放有限 A_OL=1e6（Q 越高越敏感），与 v1.0 §2 的结论一致。SK 对照：Q=1/3、峰值增益 0.3333，机器精度。**Q 从 1/3 提升到 10（30×）在 MFB 下是可设计的**，§6 的结构约束被解除。

### 11.3 ρ 解耦峰值增益

`H0 = 2Q²/(1+ρ)` 意味着 Q 与增益并非完全绑定：固定 Q=5，ρ ∈ [0.25, 4] 可把 H0 从 40 调到 10（4× 范围），仿真与解析最大相对误差 **0.0055%**。代价是噪声增益 `NG ≈ 1+H0` 同步变化（41 → 11），直接影响下一节的运放带宽需求。

### 11.4 有限 GBW：高 Q 不免费（核心负结果）

把 §7.1 的单极点限流宏模型（GBW 可扫、A0=1e6 与理想网表对齐、SR 恒为 10 V/µs）接入 MFB，扫描 GBW = 20 kHz–100 MHz × Q ∈ {1, 5, 10}。退化严格单调：

- GBW=20 kHz 时，Q=10 的峰值增益掉 **32.87%**、中心频率下移 **37.92%**；Q=1 仅 −1.34% / −7.63%。
- GBW=100 MHz 时，Q=10 收敛到 −0.027% / −0.020%，只剩有限 A0 与样条精化残差。

以「|Δf0| < 1%」为判据，log-log 插值得到所需 GBW：

| Q | NG = 1+H0 | GBW@1% f0 | GBW/f0 | 经验式 `100·f0·Q²` / 实测 |
|---|---|---|---|---|
| 1 | 2 | 0.159 MHz | 100× | 1.0× |
| 5 | 26 | 0.783 MHz | 492× | 5.1× |
| 10 | 101 | 1.561 MHz | 981× | **10.2×** |

**结论**：所需 GBW 随 Q 近似**线性**增长（Q 增 10×，需求增 9.84×），而教科书常用的 `GBW ≥ 100·f0·Q²` 在本拓扑下对 Q=10 **高估 10.2×**——按该式选型会白白付出一个数量级的运放带宽成本。这个预设被数据否证，如实保留。

### 11.5 容差与灵敏度（延续 v1.1 §9 方法学）

±5% 均匀独立扰动 5 个元件，n=20000 解析抽样（向量化 `mfb_bp_params_array`），与灵敏度 L2 范数 × tol/√3 的误差传播式对照：

| Q | σ(f0)/f0 MC | 解析 | MC/解析 | σ(Q)/Q | σ(H0)/H0 |
|---|---|---|---|---|---|
| 1 | 2.7043% | 2.7003% | 1.0015 | 1.7588% | 4.5519% |
| 5 | 2.7069% | 2.7003% | 1.0024 | 1.7702% | 4.5788% |
| 10 | 2.7071% | 2.7003% | 1.0025 | 1.7555% | 4.5261% |

并列对照：v1.1 SK 低通解析 σ(fc)/fc = 2.8868%。**Q 的容差敏感性与目标 Q 无关**（三档 Q 的 σ 几乎相同），因此「高 Q 更怕容差」的直觉并不成立——高 Q 的真实代价在 §11.4 的 GBW，而非元件散布。

解析灵敏度（ρ=1）给出干净的对消性质：`S(f0)` 对 C1/C2/R3 均 −0.5、对 R1/R2 各 −0.25；`S(Q)` 对 **C1/C2 精确为 0**（(C1+C2) 与 C1C2 的弹性对消，与 v1.1 §9.2「f0 处 C1 灵敏度为 0」是不同的解析机制）；`S(H0)` 对 R2 精确为 0、对 R3 为 +1。

## §12 深化 E：噪声分析（`.noise`，补 §6 遗留项）

### 12.1 ngspice `.noise` 输出协议

`.noise v(out) V1 dec <ppd> <fstart> <fstop>` 在 raw 中写出**两段** plot，需扩展解析口径（v1.0 只处理 AC/Transient）：

```
'Noise Spectral Density Curves' → frequency / onoise_spectrum / inoise_spectrum   [V/√Hz]
'Integrated Noise'              → v(onoise_total) / v(inoise_total)               [V rms]
```

`inoise_spectrum = onoise_spectrum / |H(V1→out)|`（输入参考）。ngspice 在 **T = 27 °C = 300.15 K** 计算，故 `√(4kTR)@1 kΩ = 4.0714e-9 V/√Hz`，与实测低频 `onoise_spectrum[0]` 精确吻合。

### 12.2 kT/C 三重验证

一阶 RC 的等效噪声带宽 `ENBW = 1/(4RC)`，故输出总噪声 `√(4kTR · 1/(4RC)) = √(kT/C)` **与 R 无关**。三种口径对照（C=1 µF，`√(kT/C) = 6.4374e-8 V rms`）：

| R (Ω) | fc (Hz) | √(4kTR) 解析 | ngspice 低频密度 | ngspice 总噪声 | 相对误差 |
|---|---|---|---|---|---|
| 1 k | 159.15 | 4.0714e-9 | 4.0714e-9 | 6.4368e-8 | −0.009% |
| 10 k | 15.92 | 1.2875e-8 | 1.2875e-8 | 6.4357e-8 | −0.027% |
| 100 k | 1.59 | 4.0714e-8 | 4.0713e-8 | 6.4241e-8 | −0.207% |

R=100 kΩ 的 −0.207% 全部由扫频下界 0.01 Hz 截掉的低频功率解释（ENBW 仅 2.5 Hz），不是求解器误差。谱数值积分用 `df = f·d(ln f)` 变量替换，避免对数网格上线性梯形对 1/f² 尾部的高估。

### 12.3 二阶带通 ENBW

`∫|H|²df = H0²·π f0/(2Q)`，即归一化 ENBW = (π/2)×(−3dB 带宽)。解析式、谱积分、ngspice `onoise_total` 三者对照，白噪声近似（把 f0 处输入参考密度当作谱内常数）误差 **≤0.22%**：

| Q | H0 | ENBW (Hz) | onoise_total (V rms) | 白噪声近似误差 |
|---|---|---|---|---|
| 1 | 1 | 2 500 | 1.5757e-6 | +0.18% |
| 2 | 4 | 20 000 | 2.7276e-6 | +0.21% |
| 5 | 25 | 312 500 | 6.4574e-6 | +0.21% |
| 10 | 100 | 2 500 000 | 1.2626e-5 | −0.16% |

输出总噪声 ~ **Q^0.909**（拟合），与理论 Q¹ 一致：H0 ∝ Q²、√ENBW ∝ Q⁻¹ᐟ²、电阻热噪声密度 ∝ Q⁻¹ᐟ²（因 R ∝ 1/Q）三者相乘。

### 12.4 运放 e_n 的严格 SPICE 建模技巧

`.noise` 只对内建器件（电阻）产生噪声，B 源/VCVS 无噪声。为使运放电压噪声也走 SPICE 而非解析拍脑袋，取 `R_eq = e_n²/(4kT)`（e_n=10 nV/√Hz → R_eq ≈ 6033 Ω），把它**串在同相输入端到地**：

```
Ren 0 en <R_eq>
E1  out 0 en n2 1e6
```

VCVS 输入不取电流 ⇒ 该电阻上无 DC/AC 压降，**传递函数严格不变**（单测 `test_en_resistor_leaves_ac_response_unchanged` 锁定逐点一致）；但 `.noise` 会把它的热噪声按噪声增益放大到输出。于是运放电压噪声变成一个可严格计算的真实噪声源，而非外部叠加假设。电流噪声 `i_n` 仍以一阶解析式 `i_n·R3` 折算（报告如实标注，未做 SPICE 噪声源建模）。

### 12.5 阻抗标度：不存在最优 α（负结果）

保持 f0/Q/H0 严格不变的阻抗标度 `R→αR, C→C/α`（`scale_passive_network`）：α 扫描 0.1–10，每个 α 跑「仅无源」与「无源+e_n」两次 `.noise`，用功率平方差分解 e_n 项。

| α | 无源 (Vrms) | e_n 项 (Vrms) | i_n 项 (Vrms) | 总噪声 (Vrms) | SNR (dB) |
|---|---|---|---|---|---|
| 0.10 | 2.042e-6 | 1.511e-5 | 1.511e-5 | 2.146e-5 | 93.37 |
| 1.00 | 6.457e-6 | 1.511e-5 | 1.511e-4 | 1.520e-4 | 76.37 |
| 10.0 | 2.042e-5 | 1.511e-5 | 1.511e-3 | 1.511e-3 | 56.41 |

实测幂律：无源 ~ **α^0.500**、i_n ~ **α^1.000**、e_n 项离散度 **0.000%**（4.1e-10 %，与 α 无关，印证 §12.4 的技巧）。三项中没有一项随 α 增大而减小 ⇒ **总噪声在 α 上单调递增，不存在内点最优**；噪声地板 = 1.511e-5 Vrms，完全由运放电压噪声决定，SNR 天花板 ≈ 96.4 dB（1 Vrms 信号）。

预设「存在一个最优阻抗标度使噪声最小」被数据否证。工程上降低阻抗是单调有利的，直到受运放输出驱动能力与功耗约束——该约束不在本模型内，如实列为边界。i_n 量级 0.01–10× 敏感性扫描同样全部单调，结论不依赖电流噪声假设。

## §13 深化 F：压摆瞬态与全功率带宽

### 13.1 小信号带宽与 FPBW 的分离

v1.1 §7.5 只验证了方波边沿斜率（SR 实测 +0.028%）。本轮把两个常被混用的「带宽」拆开：

```
小信号闭环带宽  f_cl  = GBW/NG = 10 MHz / 11 = 909.09 kHz   （与幅度无关）
全功率带宽      FPBW  = SR/(2π Vp)                            （∝ 1/幅度）
```

Vin 从 0.01 V 到 1 V，FPBW 从 15.9 MHz 降到 159.15 kHz，跨度 **100×**；在 1 V 输入时小信号带宽是 FPBW 的 **5.71×**。仅看 AC 扫频会严重高估大信号可用带宽。

### 13.2 THD 在 slew_ratio 轴上 collapse

统一频率网格 1 kHz–3 MHz × 5 档幅度（55 次瞬态，每周期 200 点、24 周期、稳态后 50% 段 FFT、谐波取 ±3 bin 邻域峰值）。横轴取 `slew_ratio = 2πf·Vp/SR`：

- 小幅度（0.01/0.05/0.1 V）全频段 THD ≈ 0.001%（数值底噪），最大斜率 0.588/2.941/5.883 V/µs（未触 SR=10）。
- 大幅度（0.5/1.0 V）在 3 MHz 时 THD = 9.563%/11.363%，最大斜率钉在 **10.379/10.546 V/µs**（≈SR），Vpp 明显塌陷。

不同幅度的失真曲线在 slew_ratio 上重合——**决定失真的是所需斜率与 SR 之比，而非频率或幅度本身**。

### 13.3 FPBW 是保守下界（方法学坑）

粗网格（等比数列）插值给出 THD=1% 起始频率 / FPBW = 1.41× / 1.61×，两幅度不一致。在 FPBW 附近细扫 ratio ∈ [1.0, 2.5] 后：

| Vin | THD@1.0×FPBW | THD@1.4×FPBW | THD@2.5×FPBW | 1% 起始 / FPBW |
|---|---|---|---|---|
| 0.5 V | 0.001% | 4.732% | 8.730% | **1.183** |
| 1.0 V | 0.001% | 7.524% | 10.981% | **1.165** |

两幅度离散度仅 **1.51%**，collapse 成立。**FPBW 处波形尚未失真**——它只是「正弦最大斜率恰好等于 SR」的临界点，斜率刚触限时尚未产生可观谐波；THD 达 1% 需要约 1.17× 过驱动。因此 FPBW 是**保守下界**，而不是失真起始频率；粗网格的 1.41/1.61 是稀疏频点上的插值伪影。教训与 v1.1 §7.4 一致：**先固定判据与网格密度，再比较频率**。

### 13.4 低 SR 阶跃的建立时间延长

SK 低通（f0=1 kHz，Q=0.707）+ 跟随器宏模型，固定 ΔV=5 V，只扫 SR（保持 GBW 不变）：

| SR (V/µs) | ΔV/SR (µs) | 10–90% 上升 (µs) | 2% 建立 (µs) | 上升/线性基准 |
|---|---|---|---|---|
| 0.005 | 1000.00 | 1223.30 | 2168.83 | **3.58×** |
| 0.010 | 500.00 | 478.10 | 1151.33 | 1.40× |
| 0.020 | 250.00 | 341.75 | 949.01 | 1.00× |
| 0.050–10 | ≤100 | 341.75 | 949.01 | 1.00× |

线性基准 341.75 µs 与 v1.1 §8.3 的 2 阶 Butterworth 342 µs 一致。当 `ΔV/SR` 超过线性上升时间时，实测上升时间被压摆下限拖长且略高于下限（滤波器自身响应叠加），建立时间同步劣化；反之完全不受影响。**存在一个明确的临界 SR ≈ 0.015 V/µs**，工程上可直接用 `ΔV/SR < t_r,linear` 判定。

## §14 v1.2 结论

1. **§6 的两个遗留项已闭合**：MFB 带通把 Q 从 1/3 解放到 10（AC vs 手推解析式 ≤1.73e-3 dB，`H0=2Q²/(1+ρ)` 解耦增益）；`.noise` 把 kT/C（0.009–0.207%）与带通 ENBW（白噪声近似 ≤0.22%）三重验证到位。
2. **两个负结果**：`GBW ≥ 100·f0·Q²` 在 MFB 高 Q 下高估 10.2×（实际需求 ∝ Q 线性）；阻抗标度下噪声单调递增、**无内点最优**，地板由运放 e_n 决定。两者均如实保留，未改写成「符合预期」。
3. **方法学延续**：v1.1 §9 的解析误差传播在 MFB 上再次命中 MC（比 1.0024）；v1.1 §7.4 的插值教训在带通峰值精化（§11.2）与 FPBW 细扫（§13.3）两处复用，避免网格伪影被误读为物理结论。
4. **大信号带宽必须与小信号带宽分开报**：THD 只由 `2πf·Vp/SR` 决定，FPBW 是保守下界（1% 失真在 1.17× FPBW），低 SR 阶跃可把建立时间拖长 3.58×。
5. **严格建模技巧**：用同相输入串联等效电阻把运放 e_n 变成 ngspice 可算的真实噪声源，且传递函数逐点不变；比解析拍一个噪声增益更可验证。
